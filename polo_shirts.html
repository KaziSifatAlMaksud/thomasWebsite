Check our size guide on each product page, which lists chest measurements for every size. If you're between sizes, we recommend sizing up for a more relaxed fit.

Personalised polo shirts can be returned if faulty or if we made an error. For sizing exchanges, we'll re-personalise the correct size at no extra cost.
